# Homogeneity Testing for Poisson Processes

**Statistical hypothesis testing, Monte Carlo simulations, and an application to Danish fire insurance claims — implemented in R.**

## Overview

A homogeneous Poisson process assumes that events occur at a constant rate over time. In many applications, such as reliability analysis or insurance claims, the event rate may instead change.

This project investigates how to distinguish a **homogeneous Poisson process (HPP)** from a **non-homogeneous Poisson process (NHPP)** with increasing intensity:

$$
H_0: \lambda(t) = \lambda_0
\qquad \text{vs.} \qquad
H_1: \lambda(t) \text{ is increasing and non-constant}.
$$

The analysis combines theoretical test construction, Monte Carlo experiments, and a case study using Danish fire insurance claim arrival dates from 1980 to 1990.

## Methods

Two tests are implemented using the event arrival times $0 < T_1 < \cdots < T_n < T$, conditional on observing $n$ events over $[0,T]$.

| Test | Statistic | Null distribution | Rejection direction for increasing intensity |
| --- | --- | --- | --- |
| **Laplace-type test (L)** | $\displaystyle Z_L = \sqrt{12n}\left(\frac{1}{n}\sum_{i=1}^n \frac{T_i}{T}-\frac12\right)$ | Approximately $\mathcal N(0,1)$ for large $n$ | Large values |
| **Chi-squared test (Z)** | $\displaystyle Z = 2\sum_{i=1}^n\log\left(\frac{T}{T_i}\right)$ | Exactly $\chi^2_{2n}$, conditional on $n$ | Small values |

Under $H_0$, conditional on the number of events, arrival times have the same distribution as the order statistics of independent uniform samples on $[0,T]$.

## Experiments

The R analysis includes:

1. **Process simulation:** homogeneous Poisson processes and non-homogeneous processes generated by thinning.
2. **Null-distribution checks:** empirical distributions of the test statistics compared with their theoretical references.
3. **Power analysis:** Monte Carlo estimates of rejection rates under affine, power-law, and piecewise-constant intensity functions.
4. **Real-data case study:** analysis of event times from the `evir::danish` dataset, including a year-by-year exploration and Bonferroni multiple-testing correction.

## Findings

- The full-period analysis of Danish fire insurance claim arrivals (1980–1990) reports **strong evidence against a constant event rate** at the 5% significance level.
- The exploratory annual breakdown suggests that **changes in intensity across years** may help explain the non-homogeneity observed over the full period.
- Monte Carlo experiments show how the relative power of the two tests depends on the shape of the alternative intensity function.

These findings summarize the original analysis; the annual date preprocessing and final power-comparison conclusions should be checked before treating the results as fully reproduced.

## Running the analysis

**Requirements:** R and the packages `rmarkdown`, `knitr`, `evir`, and `lubridate`.

```r
install.packages(c("rmarkdown", "knitr", "evir", "lubridate"))
```

Save the accompanying analysis as `poisson_homogeneity.Rmd`, then render it with:

```r
rmarkdown::render("poisson_homogeneity.Rmd", output_format = "html_document")
```

The `danish` dataset is provided by the `evir` R package; no separate data download is required.
